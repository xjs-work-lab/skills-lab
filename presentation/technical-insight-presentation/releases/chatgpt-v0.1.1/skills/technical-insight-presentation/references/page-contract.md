# Per-page detailed slide contract
Each page before production: 1. audience question, 2. full take-away statement, 3. EXACT visible copy/title/subtitle/blocks, 4. previous+next page bridges, 5. visual reading order and why each block exists, 6. chart axes/nodes and benchmark record (device/model/metric/baseline/units), 7. all arrow from/to/branch-condition/type, 8. source claim IDs/URLs and direct scope, 9. native-editable versus movable raster choice, 10. Notes Part I explanation and Part II each original source, 11. potential audience misinterpretation and QA. No shallow bullet-only outline. Visible information must be understandable without having to guess an internal code name.
