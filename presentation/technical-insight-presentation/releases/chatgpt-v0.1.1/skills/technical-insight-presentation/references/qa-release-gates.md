# Technical Insight Presentation QA release gates
G0 research: original claim/source/boundary/measurement scope and current decision state complete.
G1 narrative: full-sentence conclusion page headlines, dependency from previous slide and to next, leadership decision relation.
G2 evidence: every number traced to original source, same workload/device/model/baseline/unit/metric layer, competing route and caveats visible or in note. No unsupported novel ISA/SoC claims.
G3 visuals: shared page background/title band, typography, subdued decorative asset and lower citation safe margin, numbered pages, native editable shapes, correct arrow endpoint orientation, no clipping/overlap, high-resolution projection readability.
G4 notes: each actual PPTX slide has Part I detailed page walkthrough BEFORE Part II per-source reasoning, plus correct URLs and limits.
G5 revision: edits respect authorized mutation set; compare slide/notes XML, native text, hyperlinks, data, media and render as appropriate; no silent changes.
G6 release: PPTX zip valid, correct slide count, renders PDF/all PNG/contact sheet, speaker notes and source links retained, user acceptance state honest. Actual Microsoft PowerPoint/projector verification is separate unless performed. Offer full files and QA report.
