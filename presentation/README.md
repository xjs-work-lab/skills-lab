# Presentation Skills

Skills that turn verified research, engineering analysis, and technology strategy into usable audience-facing artifacts.

- [**Technical Insight Presentation**](technical-insight-presentation/SKILL.md) — evidence-backed technical leadership slide decks, editable PPTX, explained figures, detailed source-aware presenter notes, change-control and final QA. **v0.1.0 candidate**.

Scope boundary: this area owns **presentation/storytelling, scientific visual communication, and artifact QA**; it does not replace research/evidence verification or repository operations.
